1. Exact target.  StoppingCorrect <-> N_eps and C_eps (a tautology).
   N_eps: every first-crossing survivor has r >= eps*K odd runs.
   C_eps: no first-crossing survivor has r >= eps*K odd runs.
   The repo's frozen node is N_eps; it is the few-run exclusion made uniform and
   does NOT imply CST.  Every many-run survivor lives in C_eps, including cycles
   whose crossing prefix has >= eps*K runs (a sub-problem of many-circuit cycles,
   no known mechanism).  Typical ballot word: r ~ 0.37 K, so N_eps with eps < 0.37
   excludes only an entropically thin corner.

2. Strongest finding (two parts).
   (a) Single-congruence lemma: for a word v (length m, K ones, D = 2^m - 3^K > 0)
       and E >= 0,  { n >= 2 : traceWord n m = v and T^m n = n + E }
                  = { n >= 2 : n = (N - 2^m E)/D in Z }.
       Integrality alone forces the residue class (D = -3^K mod 2^m), so all r
       run-to-run admission equations (Cramer, det = D) carry exactly ONE
       congruence.  Multiplying run bounds loses magnitude only; a short run pins
       q_i in {1,2,3} bits.  Amortised run bookkeeping is closed.
       Exact CST: for every first-crossing v, [N*3^-K mod D] > (N - 2D)/2^m,
       window <= K/(3u), u = 2^m/3^K in (1,2] (Lean: overshoot_modEq,
       three_mul_overshoot_lt).  Reviewer brute-forced this criterion to m = 21.
   (b) Control population: under 5n+1 the starts 13, 17 (cycles, E = 0) and 5
       (enters the 13-cycle from below; m = 274, K = 118, 39 odd runs, E = 8) are
       first-crossing survivors of the same admission equations.  Any C_eps
       mechanism valid for every odd multiplier is false: it must consume the
       ballot entropy deficit (|B_m| = 2^((0.950+o(1)) m)) or the verified range.
       3n-1 has no survivor at all (N < 0), so the sign control for CST is
       vacuous; the sign control for CrossingExists is 3n-1 at n = 5.
