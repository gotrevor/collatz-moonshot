# Reading notes

This directory tracks original summaries and bibliographic notes, not source papers.
PDFs are intentionally ignored by Git and are not redistributed. A summary may mention
the filename of a private working copy; use the DOI, arXiv identifier, or publisher
citation in the note to locate the source lawfully.

The summaries are research notes rather than peer-reviewed scholarship. Verify a claim
against the primary source before using it as the statement of a Lean axiom.
