# Catalytic palette: exact count ledger and bounded borrowability checkpoint

```sh
./experiments/catalytic_palette.py test
./experiments/catalytic_palette.py ledger 71
./experiments/catalytic_palette.py closure --max-label 3077 --max-rounds 6 --target 71
```

These controls use the published virtual certificate for 71 and its **known**
65-step trajectory.  The trajectory is a comparison target, not a discovered
path for an unknown start.  The script imports `experiments/research_lifts.py`
for the existing exact Collatz and pair-fiber routines.

## Forced net move counts for the published 71 certificate

Let `t` be the number of factors 2, `k` the number of odd generators,
and `m1,m5` the multiplicities of `r1,r5`.  Quadratic exchanges preserve all
four counts.  Write `a,b,d` for signed net insertions of `U8,U13,U2`, and `c`
for the signed net number of forward essential cubics
`{5,55,83} -> {11,13,17}`.  Then

```
Δt  = 3a + 5b + d
Δk  = 5a + 8b + d
Δm1 = d
Δm5 = b - c.
```

The coefficient determinant for `a,b` is -1, so these equations give a unique
integer net recipe for any endpoints.  The virtual 71 certificate has
`(t,k,m1,m5)=(16,16,0,1)`; the actual 65-step path has `(28,37,0,1)`.
Hence every repair from that certificate to the canonical 65-step path from 71 to 1 using
only these rules has

```
net U2 = 0,  net U8 = +9,  net U13 = -3,
net forward cubic = -3.
```

In particular, it requires at least nine U8 insertions, three U13 removals,
and three *reverse* essential cubics.  This is a necessary count condition,
not a reachability proof.  Extra `1,2` cycles add equal `U2` on the target and
change only its net U2 count; the other three numbers remain fixed.  The 7
control gives net `U8=-1`, with the other three zero, consistent with the
earlier successful repair.

The ledger does **not** solve the full integer relation lattice on odd labels:
after these forced net moves, the remaining target-source vector still has to
be generated by quadratic exchanges in a usable context.  That is the next
exact certificate to seek.  A rational linear-span computation or a finite
graph failure would not settle this integer and availability question.

## Small borrowability closure

Start with labels in U2, U8, and U13:
`{1,5,7,11,17,19,25,29,55,65,83}`.  If `a,b` are borrowable, their unit
witnesses can be combined, and any exact quadratic replacement
`r_a r_b = r_c r_d` makes `c,d` borrowable.  The probe applies this rule in
simultaneous rounds.  It enumerates the **complete** two-factor fiber for
each evaluated input pair; only future input labels are limited to 3077.
An output above 3077 may still witness a smaller label.  The cubic is not
needed for the displayed discoveries: its two sides are in the seed except
13, which the first quadratic round supplies.  This is a quadratic-only
closure after unit seeding, not a census of every move sequence in the
enlarged palette.

At the first round, `r11 r17 = r7 r121 = 11/26`, so 121 is borrowable.  Also
`r19 r29 = r13 r95 = 19/44`, giving 13 and 95.  At the second round,
`r35 r65 = r23 r1625 = r25 r247`; these give 23 and 247.  The persistent
tests check those equalities against hand-calculated rational values through
the actual CLI.

| Rounds | Labels at or below 3077 | Odd labels of known 71 path still missing |
|---:|---:|---:|
| 0 | 11 | 36 |
| 1 | 19 | 33 |
| 2 | 34 | 30 |
| 3 | 80 | 27 |
| 4 | 171 | 20 |

| 6 | 526 | 5: `911,1367,1619,2429,3077` |

The round-six run evaluated 54,615 pair fibers and encountered 1,901 distinct
outputs above the input ceiling.  It did not exhaust the closure.  Missing
labels are **not** an obstruction: later rounds, inputs above 3077, or a
different certificate path may supply them.  Conversely, borrowability of
every target label alone would not supply the needed integer quadratic
relation.  The exact count ledger is the durable necessary condition found here;
there is no repair of 71 yet.

Validation: five external pytest tests pass through the real CLI.  The tests
cover the 71 and 7 count ledgers, independently calculated pair identities,
and the explicit incomplete-search flag.  No general Collatz claim follows.

The complete finite witness snapshot is saved in `experiments/borrowable_palette_71.json`.  The general [lattice-and-borrowing reduction](RESEARCH-2026-09-27-borrowable-catalysts.md) explains how a future integer relation witness and these borrowability derivations can combine into an executable repair.
