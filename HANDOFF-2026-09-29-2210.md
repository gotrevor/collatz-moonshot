## 🧠 Context to carry forward

The one thing worth knowing, because it is a real mathematical result of the lap and it
contradicts the source docs: **the signed-orbit machinery the paper prescribes is
unnecessary.** Both `RESEARCH-2026-09-29-bounded-small-merger.md` and the kickoff route the
contracting-slope case through ℤ — write `b = 2^d(n/3^q) − L`, note `b ≡ −L (mod 2^d)`,
invoke a *parity transport lemma* so `b` and the negative integer `−L` share their first
`d` parity letters, then argue `z = T_ℤ^d(−L) < 0`. If a future lap reads those docs it
will build `stepZ` iteration, a signed affine dictionary and a transport lemma. **Don't.**

All that apparatus establishes exactly one inequality, `y < 3^a n` for `y = tstep^[d] b`.
Unfolded through the affine relation, that inequality *is*

```lean
tstep^[d] b < N * 3 ^ ones (traceWord b d)      where N = n / 3^q and b < N * 2^d
```

which is a **scaled strict growth bound**, proved by a single induction on `d` entirely in
ℕ (`tstep_iterate_lt` in the file):

```lean
∀ d C x, 0 < x → 0 < C → x < C * 2 ^ d → tstep^[d] x < C * 3 ^ ones (traceWord x d)
```

The induction carries the constant: an even letter halves the 2-budget with `C` fixed; an
odd letter replaces `C` by `3 * C`, because `x` odd against `x < C*2^(k+1)` forces
`x ≤ C*2^(k+1) − 1`, hence `2 * tstep x = 3x + 1 ≤ 3C*2^(k+1) − 2 < 2 * (3C * 2^k)`. That
factor-2-for-factor-3 trade is precisely the slack the final contradiction consumes. So
`L` is never constructed, `FrontB/Negative.lean` is never used, and there is no transport
lemma anywhere in the file.

Second operating decision: the master equation is kept **additive** over ℕ throughout —
`3^p * b + gw = 2^d * 3^i * n + 2^d * 3^i` with `gw = 2^j + numer v` — rather than
subtracting. Natural subtraction never saturates, and `omega` closes the linear steps.
(`gw` is the kickoff's `g`; `numer`/`ones` prepend rather than append, so the constant
recursion is `g(false::t) = 2·g t` and `g(true::t) = 2·g t + 3^(ones t)`, *not* the
kickoff's "×3 on an odd extension". The `le_g`/`g_le` bounds are stated for the prepend
recursion and both still come out as `3^p ≤ g ≤ 2^(k−p)·3^p`.)

Also: the kickoff's countercontrol is written `27 → 41 → 62 → 31`, which under `tstep`
means the *smaller* seed `27` reaches `31` in three steps. The meeting is therefore at
`i = 0` on `n = 31` and `j = 3` on `b = 27`. My first anchor had it reversed and `decide`
caught it — worth remembering that the decision procedure is a real check here, not
decoration.
