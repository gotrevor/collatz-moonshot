## 🧠 Context to carry forward

The mental model that made this tractable, and that a successor should not have to rebuild:

- **`AllowedMove.quadratic` already does context lifting for free.** Its hypothesis is
  `legalPairMove m.1 m = true` — note the state argument is `m.1` itself, so the
  availability clause inside `legalPairMove` is the tautology `m.1 ≤ m.1`. The constructor
  is stated on `(t, rest + m.1) → (t, rest + m.2)`, so *all* the real work is producing
  the witness `rest` with `rest + ↑m.1 = state`. Once you see that, the whole proof is
  "find the decomposition", not "check a predicate".
- **Availability must not go through `Multiset ≤`.** First design used
  `decide ((rem : Multiset ℕ) ≤ s.2)`; that is permutation-search decidable and the state
  reaches ~4400 odd factors over 3281 steps, so it would never finish in `native_decide`.
  Replaced by `eraseList` (one-at-a-time `∈` + `erase`). This is the load-bearing idea:
  it is linear *and* `eraseList_spec` hands you `rest + ↑l = m`, i.e. exactly the shape
  above. Do not "simplify" it back to a `≤` test.
- **`W` is derived, never inserted.** `deriv u = deriv a ++ deriv b ++ [Q [a,b] [c,d]]`
  for a DAG node, and a seed label resolves to `U2` for 1, `U8` for `19,25,29,55,83`
  (including the 55/83 shared with `U13`), `U13` otherwise. The 96 DAG labels are distinct
  and disjoint from the unit labels — checked, not assumed. Unfolding is exponential in
  principle but here costs only **1506** actions.
- **Return is the literal formal inverse** of the build block (list reversed,
  `Q(r,i) ↦ Q(i,r)`, insert ↦ remove) replayed in context `y`. That is why the third edge
  needs no new reasoning: the `W`-part evolves as the exact reverse and the `y`-part is
  untouched.
- **Approach not taken**: a Boolean "trace accepted" theorem as the primary artifact. The
  kickoff allows it but then demands a separate soundness bridge anyway, so it is strictly
  more work than making the interpreter the *only* artifact and proving `step_sound` once.
- The JSON's advertised `borrow_unit_factors = 7061` on 109 coordinates is **2667 twos +
  4394 odd factors on 108 odd labels**, label `0` being the twos coordinate. Worth knowing
  before you think a recomputation disagrees with the data.
